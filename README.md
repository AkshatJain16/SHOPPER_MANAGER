# 🛒 Inventory Management App

A simple Inventory Management web application built using **HTML**, **CSS**, **JavaScript**, **Axios**, and **CRUD CRUD API**.

The application allows users to add products, view them, and update their stock quantity using Buy buttons.

---

## 🚀 Features

- ➕ Add new products
- 📋 Display all products from the server
- 🔄 Persistent data using CRUD CRUD API
- 🛍️ Buy 1, Buy 2, and Buy 3 functionality
- 📉 Quantity updates instantly on both UI and server
- ⚡ Uses Axios for API requests
- 📱 Responsive and modern UI
- 🎨 Gradient-based styling with hover effects

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Axios
- CRUD CRUD API

---

## ⚙️ How It Works

### Add Product

Enter:

- Item Name
- Description
- Price
- Quantity

Click **Add Item** to save it to the server.

---

### Display Products

When the page loads, all products are fetched from the server using a GET request and displayed on the screen.

---

### Buy Buttons

Each product has three buttons:

- Buy 1
- Buy 2
- Buy 3

Clicking a button:

- Checks whether sufficient quantity is available.
- Updates the quantity on the server using a PUT request.
- Updates the displayed quantity without refreshing the page.

---

## 🌐 API Endpoints

| Method | Purpose |
|---------|----------|
| POST | Add Product |
| GET | Fetch Products |
| PUT | Update Quantity |
